# Roadmap 1,000+ ฟังก์ชัน — Factory OS

> เอกสารภายใน GO Along (โฟลเดอร์ `docs/roadmap/` ใช้วางแผน ไม่ใช่สัญญากับลูกค้า) · ตัวเลขทุกตัวในไฟล์นี้คำนวณจาก [`functions.json`](functions.json) ณ 3 ต.ค. 2569 (อัปเดตหลังรุ่น 0.3.0: บัญชี เงินเดือน สัญญา MA แนบไฟล์ ประวัติการแก้ไข LINE ส่วนตัว — ตรวจทีละข้อกับ route ใน `service.ts`, หน้าจอใน `ui.ts` และ kernel)

## ไฟล์นี้คืออะไร

`functions.json` คือรายการ "สิ่งที่ผู้ใช้ทำได้" (เริ่มที่ 1,000 ข้อ ตอนนี้ 1,020 ข้อ) ครอบคลุมสิ่งที่มีแล้ว สิ่งที่กำลังสร้าง และสิ่งที่วางแผนไว้ ใช้เป็นภาษากลางของทีมขาย ทีมพัฒนา และลูกค้า เวลาคุยว่า "ระบบทำ X ได้ไหม" ให้ตอบเป็นเลข F ได้ทันที

| ฟิลด์ | ความหมาย |
|---|---|
| `id` | `F0001`–`F1000` ชุดตั้งต้นเรียงตามโมดูล · `F1001`+ ฟังก์ชันที่เพิ่มภายหลัง (ส่งมอบจริงแต่ไม่อยู่ในชุดเดิม) ห้ามนำเลขที่ใช้แล้วกลับมาใช้ใหม่ |
| `module` | id ของโมดูลจริงใน `services/` หรือ id ที่เสนอสำหรับโมดูลใหม่ (มีเครื่องหมาย * ในตารางด้านล่าง) · `platform` = kernel/gateway/เว็บ/มือถือ · `tools` = `pnpm erp` และหน้าเว็บขาย · `ai` = ฟีเจอร์ AI ข้ามโมดูล · ฟังก์ชันที่ส่งมอบแล้วย้ายไปอยู่ใต้โมดูลจริงที่ทำ (เช่น สัญญา MA F0851–F0856 → `contracts`, รายงานภาษีขาย/ซื้อ ภ.พ.30 → `accounting`) |
| `area` | หมวดย่อยภายในโมดูล (ภาษาไทย) |
| `name` | สิ่งที่ผู้ใช้ทำได้ เขียนเป็นภาษาผู้ใช้ ไม่ซ้ำกันทั้งไฟล์ |
| `industries` | กลุ่มธุรกิจที่ได้ประโยชน์ (`all` = ทุกธุรกิจ) ใช้กรองทำเอกสารขายรายอุตสาหกรรม |
| `priority` | P1 = ลูกค้าเป้าหมายต้องมีก่อนซื้อ/ก่อนเลิกใช้ Excel · P2 = ทำให้ใช้งานลื่นหรือขายต่อได้ · P3 = ทำเมื่อมีลูกค้าขอและจ่าย |
| `status` | `done` = มีในโค้ดวันนี้ (ตรวจกับ route ใน `service.ts` และหน้าจอใน `ui.ts` แล้ว) · `building` = กำลังสร้าง · `planned` = ยังไม่เริ่ม |
| `effort` | S ≤ 2 วัน-คน · M 3–10 วัน-คน · L > 10 วัน-คน (ประมาณสำหรับทีมที่ใช้ Claude Code ช่วย) |

**กติกาการแก้ไฟล์:** เปลี่ยน `status` เป็น `done` ได้ก็ต่อเมื่อ `pnpm check` ผ่านและมีหน้าจอหรือ action ใน `ui.ts` แล้วเท่านั้น และ **ทุกส่วนของชื่อฟังก์ชันต้องเป็นจริง** — ถ้าส่งมอบได้แค่บางส่วน ให้คงข้อเดิมเป็น `planned` แล้วเพิ่มข้อ `F1001`+ ที่บอกสิ่งที่ทำได้จริง (ตัวอย่างด้านล่าง) ฟังก์ชันที่ลูกค้าขอเฉพาะราย (งาน custom) ไม่ต้องใส่ไฟล์นี้ ยกเว้นตั้งใจจะขายซ้ำ
