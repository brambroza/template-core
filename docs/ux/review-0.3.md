# UX review 0.3 — ทั้งระบบ 18 โมดูล (web + mobile)

ตรวจบน demo (บริษัท `demo`, admin) วันที่ 2 ต.ค. 2569 · เดสก์ท็อป 1440×900 โหมดสว่าง ทุกหน้าในเมนู (99 หน้า) +
หน้า detail หลัก, ⌘K, กระดิ่ง, นำเข้า CSV · มือถือ 390×844 โหมดมืด หน้าหลัก/รายการ/detail/เมนู/กระดิ่ง
ภาพอยู่ใน `docs/ux/review-0.3/` (ก่อนแก้ = ชื่อไม่มีคำนำหน้า `a`, หลังแก้ = `ad-*` เดสก์ท็อป, `ap-*` มือถือ)

ระดับ: **S1** ใช้งานไม่ได้/เข้าใจผิด · **S2** ทำให้ช้า ดูเป็น ERP รุ่นเก่า · **S3** ขัดตา ปรับเมื่อมีเวลา

## สรุป

renderer กลางแข็งแรงอยู่แล้ว (ภาษาไทยครบ, ⌘K ดีมาก, กระดิ่ง/toast/flow ชัด) ปัญหาใหญ่เกิดจาก "ขนาด" — พอมี 18 โมดูล
หน้าแรกยาว ~8,900px เรียงตามชนิดการ์ดจนโมดูลกระจัดกระจาย, เมนูยาว 4,300px, และตารางที่มีคอลัมน์มากบีบเลขเอกสารจนตัดเป็น 3 บรรทัด
รอบนี้แก้ที่ renderer/สไตล์กลางทั้งหมด จึงดีขึ้นทุกโมดูลพร้อมกัน
