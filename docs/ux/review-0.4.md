# UX review 0.4 — บัญชี เงินเดือน สัญญาบริการ และชิ้นส่วนแพลตฟอร์มใหม่

ตรวจบน demo ใหม่ (บริษัท `demo`, admin) วันที่ 3 ต.ค. 2569 · เว็บโหมด dev · เดสก์ท็อป 1440 โหมดสว่าง + พรีวิวพิมพ์ (print media, กว้าง 794px ≈ A4)
· มือถือ 390×844 โหมดมืด · ข้อมูลเงินเดือน (5 คน, 3 รอบ), สัญญา MA (3 สัญญา, นัด PM, ผลตรวจ) และไฟล์แนบ (รูป + PDF) สร้างผ่าน API ก่อนถ่าย
ภาพอยู่ใน `docs/ux/review-0.4/` — `b-*` ก่อนแก้, `a-*` หลังแก้ (`d-` เดสก์ท็อป, `p-` มือถือ, `-print` = พรีวิวพิมพ์)

ระดับ: **S1** ใช้งานไม่ได้/เข้าใจผิด · **S2** ดูไม่เป็นมืออาชีพ ทำให้ช้า · **S3** ขัดตา

## สรุป

renderer ทำหน้าจองานเอกสารได้ดีอยู่แล้ว แต่รายงานการเงินถูกวาดเป็น "ตารางงาน" ทั่วไป: แถวหัวข้อ/รวม/ผลลัพธ์หน้าตาเหมือนบัญชีทุกแถว มี "—" ในช่องรหัส,
"0.00" เต็มตาราง, ไม่มีบรรทัดรวม, ไม่มีงวดของรายงาน, และบนมือถือกลายเป็นการ์ดที่หัวการ์ดเป็น "—" ซึ่งนักบัญชีอ่านไม่ได้
รอบนี้เพิ่มการแสดงผลแบบ "รายงาน" ที่ ui-schema + web (ข้อมูลล้วน ใช้ได้ทุกโมดูล) แล้วใช้ใน accounting / payroll / contracts — ui.ts เท่านั้น ไม่แตะ service

## เพิ่มใน `packages/ui-schema` (ข้อมูลล้วน + ฟังก์ชันที่มีเทสต์ `test/report.test.ts`)

- `Format` `'accounting'` + `accounting()`, `isNegative()`; `FieldType` `'month'`
- `Column`: `total`, `indent`, `hideRepeats`, `section`, `emphasis`, `hideZero`, `phone`
- `ListScreen.report: ReportSpec` (`subtitle`, `rowKind`, `heading`/`subtotal`/`total`/`muted`, `levels`/`indentFrom`, `check`, `totalLabel`)
- `DetailScreen.lines[].half`
- helpers: `reportRowStyle`, `reportIndent`, `columnTotals`, `repeatsAbove`, `fillTemplate` (`|date |month |year |money`), `filterGroups`, `datePresets`, `factSections`, `auditDetailText`
- mobile ไม่อ่านคีย์ใหม่ (ยังแสดงรายการ/ข้อมูลแบบเดิม); `accounting` ใช้ `formatValue` จึงขึ้นรูปแบบเดียวกันบนมือถือ; `month` เป็นช่องพิมพ์ — ไม่ได้แก้ apps/mobile
