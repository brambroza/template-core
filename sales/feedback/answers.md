# คำตอบต่อ feedback จากรีวิวจำลอง (AI persona) — รอบ 4 (wave 4)

> ไฟล์นี้ตอบข้อที่ทีมพัฒนาแก้แล้วในรอบนี้ อ้างอิงหัวข้อใน `service-owner.md` (คุณธีรพงษ์ — persona สมมติ บริษัทบริการไอที ชลบุรี; รีวิวจำลอง (AI persona) — ใช้เป็นสมมติฐาน ต้องยืนยันกับลูกค้าจริง)
> ทีมอื่นในรอบเดียวกันเพิ่มหัวข้อของตัวเองต่อท้ายได้

## ธุรกิจบริการ — เอกสารต่อกันเป็นสายเดียว + เงินเข้า + SLA

### ข้อ 3 — ใบเสนอราคาที่ตอบรับแล้ว ต้องพิมพ์ใบสั่งขายใหม่ทั้งหมด → แก้แล้ว
- กด "ลูกค้าตอบรับ" บนใบเสนอราคา → ระบบสร้าง **ใบสั่งขายฉบับร่าง** ให้อัตโนมัติ (ผ่าน event `crm.quotation_accepted` — ไม่ผิดกฎแยกโมดูล
  ถ้าลูกค้าไม่ได้ซื้อ CRM ก็ไม่มีอะไรเกิดขึ้น)
- คงทุกอย่างจากใบเสนอราคา: ลูกค้า (รหัส เลขผู้เสียภาษี สาขา ที่อยู่) · ทุกบรรทัด · **ส่วนลดต่อบรรทัด** · ราคารวม/ไม่รวม VAT
  → ยอดตรงใบเสนอราคาทุกสตางค์ (ตัวอย่างในเทสต์: กล้อง 2,850 −5% × 4 + ค่าติดตั้ง = 15,797.48 เท่ากัน)
- บรรทัดค่าบริการ/ค่าแรงที่ไม่มีรหัสสินค้า ยกมาเป็น **บรรทัดคำอธิบาย ไม่ตัดสต็อก** (ใบสั่งขายค่าบริการล้วนไม่ส่งเรื่องตัดสต็อกไปคลัง)
- เลขใบเสนอราคาอยู่ในช่อง **"อ้างอิง"** ของใบสั่งขาย ค้นหาได้จากรายการใบสั่งขาย (พิมพ์ `QT-2569-0010`) · สร้างครั้งเดียวต่อใบเสนอราคา กดซ้ำ/ส่งซ้ำไม่เกิดใบซ้ำ
- ใบสั่งขายที่สร้างเองก็มีช่อง ส่วนลด % ต่อบรรทัด · คำอธิบาย · เลขอ้างอิง (PO ลูกค้า) · เครดิต (วัน) แล้ว
- ยังไม่มี: ปุ่มบนหน้าใบเสนอราคาที่กระโดดไปใบสั่งขาย (หน้าจอข้ามโมดูลลิงก์กันไม่ได้ — ใช้ค้นหาด้วยเลขใบเสนอราคา) และ "เปิดโครงการ" อัตโนมัติ (คนละโมดูล ยังไม่ทำรอบนี้)

### ข้อ 4 — ไม่มีรับชำระ มัดจำ หัก ณ ที่จ่าย และอายุลูกหนี้ → แก้แล้ว (ยกเว้นวางบิลตามงวด)
- **ใบเสร็จรับเงิน `RC-2569-0001`** รับชำระได้หลายใบกำกับในใบเดียว · รับบางส่วนได้ · ใบกำกับมีสถานะ ค้างชำระ / ชำระบางส่วน / ชำระครบ
  · รับเกินยอดค้าง = ระบบไม่ยอม (แจ้งยอดค้างที่ถูกต้อง)
- ชำระโดย เงินสด / โอน / เช็ค / บัตร + เลขที่เช็คหรืออ้างอิงการโอน · ชื่อผู้รับเงินเติมจากผู้ล็อกอิน · พิมพ์ใบเสร็จได้
- **หัก ณ ที่จ่าย 1 / 2 / 3 / 5%** คิดจากยอดก่อน VAT ของส่วนที่รับชำระ (ใบกำกับ 10,700 หัก 3% = 300 รับจริง 10,400) ใบเสร็จแสดงยอด หัก ณ ที่จ่าย และรับสุทธิ
- **รับมัดจำ** (ใบรับเงินมัดจำ ผูกใบสั่งขายได้) แล้วนำมาหักตอนรับชำระใบกำกับภายหลัง ระบบติดตามยอดมัดจำคงเหลือต่อใบ
- **ใบกำกับมีวันครบกำหนดชำระ** = วันที่ใบกำกับ + เครดิตของใบสั่งขาย (หรือกำหนดเอง) · QR พร้อมเพย์บนใบกำกับใช้ยอดที่ยังค้าง
- **ลูกหนี้คงค้างตามลูกค้า** (ค้าง · เกินกำหนด · ค้างนานสุดกี่วัน · หักมัดจำแล้วเหลือสุทธิ) และ **อายุลูกหนี้** ยังไม่ครบกำหนด / 1–30 / 31–60 / 61–90 / เกิน 90 วัน
  ดูย้อนหลัง "ณ วันที่" ได้ · การ์ดหน้าแรก "ลูกหนี้": ค้างรับทั้งหมด · เกินกำหนดชำระ · รับเงินเดือนนี้ — คือคำถาม "ใครค้างเกิน 60 วัน" ที่คุณดูทุกเช้า
- มี event `sales.payment_received` ให้บอทแจ้งเตือนต่อได้
- ยังไม่มีรอบนี้: ใบแจ้งหนี้มัดจำ/วางบิลตามงวด (ผูก milestone โครงการ), ใบกำกับภาษีสำหรับเงินมัดจำ, ยกเลิกใบเสร็จ, บิล MA รายเดือนอัตโนมัติ,
  สูตรบอท "ใบแจ้งหนี้เลยกำหนดชำระ" (ต้องมีตัวจับเวลา — ส่งต่อทีม automation)

### ข้อ 8 — Helpdesk ไม่ผูกลูกค้า/อุปกรณ์ และ SLA ไม่ใช่เวลาทำการ → แก้แล้ว
- **SLA นับตามเวลาทำการ** ค่าเริ่มต้น จันทร์–ศุกร์ 08:00–17:00 (เวลาไทย) + **รายการวันหยุด** ตั้งเองได้ที่ "เวลาทำการ (SLA)" และ "วันหยุด"
  → แจ้ง 23:04 คืนวันศุกร์ SLA ตอบรับ 4 ชม. ทำการ = **ครบกำหนดจันทร์ 12:00** (ไม่ใช่ตีสามอีกต่อไป)
- เรื่อง "ด่วนมาก" เลือกได้ว่านับ 24 ชม. (ค่าเริ่มต้น) หรือนับเวลาทำการเหมือนเรื่องอื่น · ปิดเวลาทำการทั้งหมดเพื่อกลับไปนับตามนาฬิกาก็ได้
- ช่างบันทึกเรื่องที่ลูกค้าโทรแจ้งย้อนเวลาได้ (เช่น โทรมา 23:04 บันทึกเช้า) SLA นับจากเวลาที่ลูกค้าแจ้งจริง (ผ่าน API ตอนนี้ — หน้าจอยังไม่มีช่องวันเวลา)
- **ผูก ticket กับลูกค้า** (ค้นจากทะเบียนลูกค้า) และ **อุปกรณ์ / Serial No.** — หน้า "บันทึกเรื่องจากลูกค้า" สำหรับช่าง · ค้นหา ticket ด้วยชื่อลูกค้าหรือ serial ได้
  → ดูประวัติปัญหาตามลูกค้า/ตามกล้องได้
- **คอลัมน์ "โดย" แสดงชื่อแล้ว** (เติมจากผู้ล็อกอิน แก้ไขแทนคนอื่นไม่ได้) · ช่างที่กด "รับเรื่อง" มีชื่อขึ้นเป็นผู้รับผิดชอบ · ผู้แจ้งเองไม่ต้องพิมพ์ชื่อ
- ยังไม่มี: ผูกสัญญา MA (ยังไม่มีโมดูลสัญญา), ปฏิทินแยกตามหมวด/ตามสัญญา, ลิงก์ประเมินความพึงพอใจให้ลูกค้ากดเอง

### ข้อ 7 — สิทธิ์ตั้งต้น: เซลส์สร้างลูกค้าไม่ได้ / PM ค้นลูกค้าไม่เจอ → เป็นการตั้งค่า role (ไม่ใช่บั๊กโค้ด)
ระบบแยกสิทธิ์ตามโมดูล ทะเบียนลูกค้าเป็นของ master-data และรายชื่อพนักงานเป็นของ identity — role ที่ใช้ในเดโมแค่ไม่ได้ให้สิทธิ์สองอย่างนี้
แนะนำ role สำหรับบริษัทบริการ (ตั้งที่ "ผู้ใช้และสิทธิ์" หรือสร้างจากแม่แบบ role):

| Role | ต้องมีเพิ่มจากสิทธิ์งานของตัวเอง |
| --- | --- |
| เซลส์ | `master.partner.read` + **`master.partner.write`** (เพิ่มลูกค้าใหม่ระหว่างทำใบเสนอราคา), `master.item.read`, `identity.user.read` |
| ผู้จัดการโครงการ | **`master.partner.read`** (เลือกลูกค้าของโครงการ), **`identity.user.read`** (เพิ่มสมาชิก/ช่างในโครงการ), `crm.quote.read`, `sales.order.read` |
| หัวหน้าช่าง / ช่าง | `master.partner.read` (ลูกค้าใน ticket), `identity.user.read` (มอบหมายงาน), `helpdesk.ticket.create/read/work`, `projects.timesheet.log` |
| บัญชี | `sales.invoice.write`, **`sales.receipt.write`**, **`sales.receivable.read`**, `master.partner.read` |

รายละเอียดเต็มอยู่ใน `services/crm/CLAUDE.md` หัวข้อ "Recommended roles" · ปุ่ม "+ ลูกค้าใหม่" ในช่องค้นหาลูกค้ายังไม่มี (ต้องขยาย renderer กลาง)
