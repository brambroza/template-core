## 2. เดโมเซิร์ฟเวอร์ — ตรวจ 6 จุดก่อนเดโมแรก

```bash
git pull && pnpm install && pnpm db:dev
pnpm --filter @erp/web build
DEMO_RESET=1 WEB_PORT=3000 ANTHROPIC_API_KEY=<key ของ GO Along> pnpm demo
# บริษัท demo · ทุกบัญชีรหัส demo1234
```

ผู้ใช้เดโม (สร้างจากแม่แบบบทบาทแล้ว): `admin@` สมศักดิ์ ศรีสวัสดิ์ (MD) · `buyer@` วิไลวรรณ จัดซื้อ · `store@` สมชาย คลังดี · `qc@` อรุณี ทองดี · `tech@` ประเสริฐ ช่างใหญ่ · `plan@` กมลชนก วางแผน · `sales@` ปิยะพงษ์ ขายเก่ง · `hr@` นภาพร ใจงาม · `acc@` สุดารัตน์ บุญมา · `it@` ธนากร พึ่งบุญ (ทั้งหมด `@demo.co.th`)

|---|---|---|
| 1 | buyer@ เปิด PO ร่างล่าสุด (เหล็ก SPCC 2.0 มม. 600 กก.) → อนุมัติ | ปฏิเสธเป็นภาษาไทย "ผู้สร้างใบสั่งซื้อ … อนุมัติเองไม่ได้" |
| 2 | store@ คลัง → จ่ายออก จากคลัง `QC-HOLD` | ปฏิเสธ · หน้า "กักกัน QC" ยอดตรงกับสต็อก · RT-2569-0001 (ส่งคืนเหล็กที่ QC ตีกลับ) เปิด/พิมพ์ได้ |
| 3 | acc@ เงินเดือน → PR-2569-09 (จ่ายแล้ว) และ PR-2569-10 (คำนวณแล้ว รออนุมัติ) | ประกันสังคมของคนเงินเดือน ≥ 17,500 = 875 |

**ห้ามโชว์ในทุกเดโม (ยังไม่แก้):** งบแสดงฐานะการเงิน (ยังไม่มียอดยกมา/ทุน เงินสดติดลบ) · ช่องกรอกวันที่ (ยังเป็น mm/dd/yyyy) · ticket ของลูกค้า MA 24x7 (SLA ยังนับเวลาทำการ) · หน้ากำไรโครงการ · กระดิ่งของคนที่ไม่ใช่ผู้อนุมัติ (99+) — และบอกก่อนเริ่มว่า "บริษัทเดโมเป็นโรงงาน ชุดข้อมูลสำนักงาน/บริการมาใน ธ.ค."
