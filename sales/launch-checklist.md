# เช็กลิสต์เปิดตัว Factory OS (เช้า 3 ต.ค. 2569)

ไฟล์นี้อยู่นอกแพ็กเกจลูกค้า (`pnpm erp pack` ไม่ส่งโฟลเดอร์ `sales/`, `site/`, `catalog/`)

## 1. ก่อน 9 โมง — สิ่งที่ต้องทำเอง (ระบบทำแทนไม่ได้)

- [ ] ใส่ช่องทางติดต่อใน `site/site.config.json` → `contact.phone`, `contact.line` (LINE OA), เปลี่ยน `email` ถ้าจะใช้อีเมลบริษัท
- [ ] (แนะนำ) สร้างที่รับฟอร์ม เช่น Google Apps Script ที่บันทึกลง Google Sheet แล้วใส่ URL ใน `contact.leadEndpoint` — ไม่ใส่ก็ได้ ฟอร์มจะเปิดอีเมลให้ลูกค้ากดส่ง
- [ ] `pnpm site` แล้วอัปโหลดโฟลเดอร์ `site/dist` ขึ้นเว็บ (Vercel / Netlify: ลากโฟลเดอร์ไปวาง หรือ `npx vercel site/dist --prod`)
- [ ] ใส่เบอร์และ LINE ในสไลด์สุดท้ายของเด็คขาย (ช่อง `[เบอร์โทร]` `[@ไอดี]`)
- [ ] แชร์ลิงก์เด็ค / หน้าเว็บตัวอย่าง จากเมนู Share ของแต่ละหน้า (ตอนนี้เปิดได้เฉพาะคุณ)

## 2. เซิร์ฟเวอร์เดโมสำหรับลูกค้า (VPS 2 vCPU / 4 GB พอ)

```bash
git clone https://github.com/brambroza/template-core.git && cd template-core
pnpm install && pnpm db:dev
pnpm --filter @erp/web build
DEMO_RESET=1 WEB_PORT=3000 ANTHROPIC_API_KEY=<key ของ GO Along> pnpm demo
# เปิด http://<server>:3000 · บริษัท demo · admin@demo.co.th · demo1234
```
- ตั้ง HTTPS ด้วย Caddy/Nginx หน้า port 3000 แล้วใส่ URL ใน `site/site.config.json` → `demoUrl`
- อยากเริ่มข้อมูลใหม่ก่อนเดโมแต่ละครั้ง: รันซ้ำด้วย `DEMO_RESET=1`
- ไม่ใส่ `ANTHROPIC_API_KEY` ก็เดโมได้ ยกเว้นปุ่ม "ถาม AI" จะบอกว่ายังไม่เปิดใช้

## 3. สคริปต์เดโม 5 นาที

1. หน้าแรก "ภาพรวมโรงงาน" — หมุนผัง 3 มิติ ชี้เครื่องสีแดง (เสีย) และตัวเลขแต่ละฝ่าย
2. กด Ctrl+K พิมพ์ `แจ้งซ่อม PRESS-03 สายพานขาด` → Enter → ฟอร์มกรอกเครื่องและอาการให้ → กดแจ้งซ่อม
3. ภายในไม่กี่วินาที กระดิ่งเด้ง "เครื่องเสีย แจ้งช่างทันที" → กดแล้วเปิดใบงาน → ผังโรงงานเครื่องนั้นเป็นสีแดง
4. เมนู ระบบอัตโนมัติ > สูตรสำเร็จรูป — โชว์ว่าเปิดบอทได้ในคลิกเดียว / สร้างกฎ "เมื่อ… ถ้า… ให้…"
5. Ctrl+K ถาม `เดือนนี้ซื้ออะไรไปเท่าไหร่` → ผู้ช่วย AI ตอบจากข้อมูลจริง + ปุ่มเปิดเอกสาร
6. เปิดใบสั่งซื้อ → แถบขั้นตอนเอกสาร → อนุมัติ → ใบกำกับภาษีพร้อม QR พร้อมเพย์
7. ปิดด้วยหน้าเลือกโมดูลบนเว็บ: เลือกตามปัญหาลูกค้า เห็นราคาทันที

## 5. ใครควรติดต่อก่อน (กลุ่มที่ปิดง่ายที่สุด)

- โรงงานที่คุณเคยทำโปรเจกต์ให้ หรือคุยค้างไว้ — ส่งข้อความส่วนตัวพร้อมลิงก์เดโม ก่อนโพสต์สาธารณะ
- โรงงานปั๊มโลหะ / ชิ้นส่วนยานยนต์ / พลาสติกฉีด ขนาด 20–200 คน ที่ยังใช้ Excel + LINE
  เปิดด้วยชุด **ซ่อมบำรุงอัจฉริยะ** (เจ็บชัด เห็นผลไว เดโมสวยที่สุด)
- ร้านซื้อมาขายไป / ตัวแทนจำหน่าย → ชุด **ซื้อมาขายไป**
- พาร์ทเนอร์ที่ขายเครื่องจักรหรือดูแลระบบ IT ให้โรงงาน — เสนอส่วนแบ่งการขาย / ให้เขาติดตั้งเอง

## 6. สิ่งที่ยังไม่มี (ตอบลูกค้าตรงๆ)

- แบบฟอร์มเอกสารเฉพาะบริษัท / เชื่อมโปรแกรมบัญชี (Express, FlowAccount) — งาน custom (man-day)
- อีเมลแจ้งเตือน, สรุปเช้าอัตโนมัติ, PM ตามชั่วโมงเดินเครื่อง — อยู่ในแผนถัดไปของโมดูลระบบอัตโนมัติ/ซ่อมบำรุง
- แอปมือถือยังไม่ได้ขึ้น App Store / Play Store (ใช้ Expo Go หรือเว็บบนมือถือได้ทันที)
