## 0. ภาพรวม

```
สัปดาห์ 0  (ก่อน go-live)  เตรียมเซิร์ฟเวอร์ · บริษัท · ผู้ใช้/บทบาท · นำเข้าข้อมูล · ค่าฐานของเกณฑ์
สัปดาห์ 1  go-live + อบรม on-site 1 วัน + ช่วยใช้งานทุกวัน
สัปดาห์ 2  ช่วยใช้งาน (hypercare สิ้นสุด) · ปิดช่องว่างข้อมูล
สัปดาห์ 3–4  ใช้งานจริงเต็มขอบเขต · วัดผลกลางทาง · ตัดสินเรื่อง must-have
สัปดาห์ 5–6  ทำงานต่อเนื่อง · เตรียมข้อมูลตัดสินใจ
สัปดาห์ 7–8  วัดผลตามเกณฑ์ · ประชุมสรุป · ใบเสนอราคาแปลง (ภายใน 30 วันหลังจบ)
```

pilot ยาว 60 วัน (~8.5 สัปดาห์) — runbook นี้เน้น **สัปดาห์ 0–6** ที่ต้องลงแรง สัปดาห์ 7–8 คือวัดผลและตัดสินใจ

**คนที่ต้องมี:** ฝั่งเรา = implementer 1 คน (+ เจ้าของในวัน kickoff/สรุป) · ฝั่งลูกค้า = champion 1 คน + ผู้ตัดสินใจ + ผู้ใช้หลัก 3–5 คน

### 1.3 นำเข้าข้อมูล (ทีมเรา + champion · 1–3 man-day ตามขนาด)

## 2. สัปดาห์ 1 — Go-live + อบรม on-site 1 วัน

### 2.1 Go-live checklist (ทุกข้อต้องเป็น ✅ ก่อนเปิดให้ผู้ใช้)

- [ ] HTTPS ใช้ได้จากมือถือ 4G · `NODE_ENV=production` + ใบอนุญาต pilot
- [ ] สำรองข้อมูลคืนก่อนทำงาน + ซ้อมกู้คืนผ่านแล้ว 1 ครั้ง
- [ ] ข้อมูลบริษัทครบ — เอกสารพิมพ์มีหัวบริษัท/เลขผู้เสียภาษี/สาขาถูกต้อง
- [ ] ผู้ใช้ทุกคน login ได้ บทบาทถูก (สุ่ม 3 คน) · ทดสอบแยกหน้าที่ผ่าน
- [ ] ข้อมูลหลักนำเข้าแล้ว champion เซ็นรับ · ยอดยกมาสต็อกตรงยอดนับ (ถ้ามีคลัง)
- [ ] LINE OA: webhook verify ผ่าน (`/m/automation/lineSetup`) · Auto-reply ใน LINE OA Manager ปิด · ผู้ใช้หลักผูก LINE (`/m/automation/lineMe` → ขอรหัส → พิมพ์ `ผูกบัญชี 123456` ในแชต OA ภายใน 10 นาที) · กลุ่มช่างได้ group ID (พิมพ์ `ไอดีกลุ่ม` ในกลุ่ม) · ทดสอบส่งแล้ว
- [ ] เปิดสูตรอัตโนมัติที่ตกลง (`/m/automation/templates`) — **เปิดเฉพาะที่เกี่ยวกับ pilot** เพื่อไม่ให้กระดิ่งรก (ผู้รับตามบทบาท = 0.3.x)
- [ ] ตัวตั้งเวลา PM (cron) หรือคนรับผิดชอบกดปุ่มทุกจันทร์ — มีชื่อคน
- [ ] ช่องทางซัพพอร์ต: LINE กลุ่มโครงการ (เรา + champion + ผู้ใช้หลัก) + กติกาแจ้งปัญหา (ภาพหน้าจอ + เวลา + ชื่อผู้ใช้)
- [ ] กติกา "ทางเดียว" ประกาศโดยผู้บริหารลูกค้า: งานในขอบเขต **ต้องเข้าระบบ** (เช่น แจ้งซ่อมใน LINE กลุ่ม ช่างตอบว่า "ขอเลข WO") · วิธีสำรองถ้าระบบล่ม (กระดาษ แล้วคีย์ย้อนหลังภายในวัน)
- [ ] วันที่วัดผลและวันประชุมสรุปลงปฏิทินผู้ตัดสินใจแล้ว

## 3. สัปดาห์ 2 — Hypercare (ช่วยใช้งาน 2 สัปดาห์แรกสิ้นสุด)

- ทุกวัน 15 นาที (ออนไลน์): ดู LINE กลุ่มโครงการ + สุ่มรายการที่ควรเข้าระบบแต่ไม่เข้า
- ปิดช่องว่างข้อมูล (สินค้า/เครื่อง/พนักงานที่ตกหล่น) — บันทึกว่าตกหล่นกี่รายการ (ใช้ปรับแม่แบบนำเข้า)
- **โรงงาน:** สุ่มนับอะไหล่ 10 รายการเทียบ `/m/inventory/balances` · ดู `/m/inventory/anomalies` (สต็อกติดลบ/ผิดปกติ) = 0
- **สำนักงาน:** ถ้ามีรอบเงินเดือนในสัปดาห์ 2–4 → **คำนวณคู่ขนาน** กับวิธีเดิม เทียบสุทธิรายคน (ส่งออก CSV จาก `/m/payroll/payslips`) ส่วนต่างต้องอธิบายได้ทุกบรรทัด ก่อนใช้ตัวเลขจากระบบจ่ายจริง
- **บริการ:** สัญญาที่มีผลทั้งหมดอยู่ในระบบ (`/m/contracts/contracts`) และ Serial ตรงกับทะเบียนลูกค้า
- จบสัปดาห์ 2: champion ทำงานประจำได้โดยไม่ต้องถามเรา — ถ้ายังไม่ได้ ขยาย hypercare 1 สัปดาห์ (บันทึก man-day)

## 4. สัปดาห์ 3–4 — ใช้เต็มขอบเขต + วัดกลางทาง

- เช็กอินรายสัปดาห์ (ข้อ 5) วัดตัวชี้วัดทุกข้อครั้งแรก (สัปดาห์ 4) → ถ้าข้อไหนต่ำกว่าเป้า > 20 จุด หาสาเหตุ: คน (ไม่ใช้) / ระบบ (ใช้ไม่ได้) / ข้อมูล (ไม่ครบ)
- must-have (เอกสารแนบ ข): ยืนยันสถานะรุ่นกับทีมพัฒนา ถ้ามีความเสี่ยงไม่ทันวัน **แจ้งลูกค้าเป็นลายลักษณ์อักษรทันที** (อย่ารอวันสรุป)
- เปิดสูตรอัตโนมัติเพิ่มตามที่ผู้ใช้ขอ (ทีละ 1–2 สูตร)
- เก็บ "คำพูดจริง" ของผู้ใช้ 2–3 ประโยค (ใช้ในกรณีศึกษาได้เฉพาะเมื่อผ่านเกณฑ์และลูกค้าอนุมัติข้อความ)

## 5. สัปดาห์ 5–6 — ต่อเนื่อง + เตรียมการตัดสินใจ

- วัดตัวชี้วัดครั้งที่ 2 (สัปดาห์ 6) — แนวโน้มต้องคงที่หรือดีขึ้น
- ทำร่างใบเสนอราคาแปลง 3 ทาง (`pnpm erp quote <ชุด> --rent --pilot`) + ตาราง TCO 3 ปีของลูกค้า (แบบ [`pricing-calculator.md`](../pricing-calculator.md)) — ใช้ตัวเลขความเจ็บปวดของลูกค้าเอง
- ถามผู้ตัดสินใจล่วงหน้า: "ถ้าผ่านเกณฑ์ ขั้นตอนอนุมัติซื้อ/เช่าในบริษัทใช้เวลากี่วัน" (หน้าต่างหักคืน 100% มีแค่ 30 วันหลังจบ)
- สัปดาห์ 7–8: วัดผลสุดท้าย → ประชุมสรุป 45 นาที (ผลเทียบเกณฑ์ · must-have · ใบเสนอราคา) → ลูกค้าเลือก ซื้อขาด / เช่า / ไม่ใช้ต่อ → ปฏิบัติตามข้อ 11 ของ pilot-agreement-outline (ส่งไฟล์ข้อมูล/ลบ ถ้าไม่ต่อ)

## 6. ตัวชี้วัดและวิธีวัด (Success metrics)

หลัก: วัดจาก **ข้อมูลในระบบ (ส่งออก CSV จากหน้ารายการ)** + **การนับจริงที่ทำซ้ำได้** · ทุกหน้ารายการมีปุ่มส่งออก CSV (UTF-8 BOM เปิดใน Excel ภาษาไทยได้) · วัดค่าฐานในสัปดาห์ 0 ถ้าทำได้
