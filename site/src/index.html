      คำถามที่พบบ่อย

      ก่อนตัดสินใจ

      ไม่ใช่โรงงาน ใช้ได้ไหม

      ได้ ชื่อ Factory OS มาจากจุดเริ่มต้นที่โรงงาน แต่วันนี้มีโมดูลสำหรับสำนักงาน (อนุมัติ เบิกจ่าย ลา/ลงเวลา จองห้อง/รถ ทรัพย์สิน) ธุรกิจบริการ (CRM ใบเสนอราคา โครงการ timesheet helpdesk) ค้าส่ง ผู้รับเหมา อาคารและโรงเรียน เลือกชุดตามธุรกิจด้านบนได้เลย

      ต้องจ่ายรายเดือนไหม คิดรายหัวไหม

      ไม่ต้อง ราคาที่เห็นคือซื้อขาด source code ต่อ 1 นิติบุคคล ไม่จำกัดจำนวนผู้ใช้ ส่วนแผนอัปเดตและซัพพอร์ตรายปีเป็นตัวเลือก (ประมาณ 20% ของราคาต่อปี)

      มีบัญชี ภาษี และเงินเดือนไหม

      ยังไม่มีในรุ่นนี้ บัญชีแยกประเภท ภาษีซื้อ-ขาย ภ.พ.30 หัก ณ ที่จ่าย และเงินเดือน/ประกันสังคม อยู่ในรุ่น 0.4 (เป้า มี.ค. 2570) ระหว่างนี้ใช้คู่กับโปรแกรมบัญชีและเงินเดือนเดิมของคุณได้ และส่งข้อมูลใบกำกับภาษีออกทาง webhook ได้

      ติดตั้งที่ไหน

      บนเซิร์ฟเวอร์ของคุณเอง หรือคลาวด์ที่คุณเลือก ใช้ Docker คำสั่งเดียว ข้อมูลอยู่กับคุณทั้งหมด

      ผู้ช่วย AI เอาข้อมูลเราไปไหน

      ผู้ช่วยใช้ API key ของบริษัทคุณเอง อ่านข้อมูลด้วยสิทธิ์ของผู้ใช้ที่ถามเท่านั้น และทำได้แค่อ่านกับเปิดหน้าจอ บันทึกหรืออนุมัติแทนไม่ได้ ถ้าไม่ใส่ key ระบบส่วนอื่นยังใช้ได้ครบ

      ซื้อแค่โมดูลเดียวได้ไหม

      ได้ ทุกการติดตั้งมีแพลตฟอร์มหลัก (ผู้ใช้/สิทธิ์ + ข้อมูลสินค้าและคู่ค้า) แล้วเลือกโมดูลอะไรก็ได้ เช่น อนุมัติออนไลน์อย่างเดียว หรือซ่อมบำรุงอย่างเดียว ซื้อเพิ่มทีหลังได้ ระบบคิดราคาชุดที่ถูกที่สุดให้เอง

      โมดูลสำนักงานและบริการใหม่ใช้จริงได้แค่ไหน

      9 โมดูลใหม่ (อนุมัติ เบิกจ่าย HR จองห้อง/รถ CRM helpdesk โครงการ ทรัพย์สิน คุณภาพ) ใช้งานได้ครบทั้งเว็บและมือถือ และกำลังเปิดรอบ pilot กับลูกค้ากลุ่มแรก และบอทแจ้งเตือน LINE รองรับเหตุการณ์ของทุกโมดูลใหม่แล้ว (ขออนุมัติ ลา เบิกเกินวงเงิน ticket ด่วน ลีดใหม่ QC ไม่ผ่าน ฯลฯ) มีสูตรสำเร็จรูปรวม 19 สูตร

      ผู้รับเหมา: มี BOQ และวางบิลตามงวดไหม

      ยังไม่มี วันนี้คุมงบโครงการ timesheet ขอซื้อ/อนุมัติ เงินทดรอง และทะเบียนเครื่องมือได้แล้ว ส่วน BOQ และวางบิลตามงวดงานอยู่ในแผนถัดจากรุ่น 0.5 ถ้าต้องการเร็วกว่านั้นทำเป็นงานพัฒนาร่วมได้

      โรงเรียน คลินิก โรงแรม มีระบบนักเรียน/ผู้ป่วย/ห้องพักไหม

      ไม่มี Factory OS ดูแลงานหลังบ้าน: ลา ลงเวลา อนุมัติ จองห้อง/รถ แจ้งซ่อมอาคาร ทรัพย์สินและครุภัณฑ์ ใช้คู่กับระบบทะเบียนนักเรียน ระบบผู้ป่วย หรือ PMS ที่มีอยู่

      ใบกำกับภาษีถูกต้องไหม

      ใบกำกับภาษีมี VAT 7% จำนวนเงินตัวอักษรภาษาไทย วันที่ พ.ศ. เลขผู้เสียภาษี/สาขา และ QR พร้อมเพย์ สามารถปรับแบบฟอร์มให้ตรงกับของบริษัทได้

      ใช้บนมือถือได้ไหม

      ได้ทั้งเว็บบนมือถือและแอป (iOS/Android) พนักงานลงเวลาด้วย GPS ยื่นลาและเบิกเงิน ผู้บริหารอนุมัติ ช่างสแกน QR ที่เครื่องหรือหน้าห้องเพื่อแจ้งซ่อม พนักงานคลังสแกนบาร์โค้ดรับ-จ่ายของได้
